# GitHub 个人主页横幅

## 内容和尺寸

两张图片均为 854 × 300，与原横幅尺寸一致。README 只替换原来的两张图片。

- 顶部：`HELLO WORLD`、`I'm Lang Tan`，不含标志。
- 底部：`END`、`Curiosity makes knowledge a game.`，含个人标志。

## 动画来源

`scripts/home-ascii.frag` 是个人网站 `src/components/logo/AsciiLogoRenderer.tsx` 的原始片元着色器副本，没有重新实现或修改其噪声公式。`scripts/sample-field.mts` 在浏览器 WebGL 中直接执行该着色器，使用横幅的实际逻辑尺寸和网页 `cellSize={6}` 对应的采样尺寸。

采样保留原始时间倍率 `uTime * 0.16`、流场扭曲、两层单纯形噪声、稳定随机阈值、呼吸因子、字符等级和 Logo 交叠处增强两级字符的逻辑。背景不是固定字符图的位移；每一格的字符来自对应时刻的着色器输出。背景颜色和 Logo 的纵向粉蓝配色沿用网页 `rowColor`。

顶部使用空 Logo 纹理，底部使用原始 `icon.svg` 的矢量标志纹理。网页使用的三维模型实时亮度纹理在这里替换为二维原始标志，因此不包含三维模型的光照细节。文字保留原 README 内容，采用网页的 380 毫秒初始等待、100 毫秒主文案打印、720 毫秒间隔和 110 毫秒副文案打印节奏。

## 图片环境的边界

GitHub README 图片不能执行 JavaScript 或 WebGL。因此最终 SVG 只播放原着色器预计算得到的字符序列，不声称在 GitHub 中实时执行着色器。

背景以每秒 12 次采样记录 24 秒，共 289 个状态，循环播放；循环末尾返回初始状态，原网页的非周期噪声不保证首尾连续。文字出场仅播放一次。图片没有外部字体、脚本或逐帧位图。系统偏好减少动态效果时显示静态完整文案。

两张 SVG 原始文件分别约 0.86 MB 和 0.87 MB，gzip 后分别约 90 KB 和 92 KB；实际传输量取决于图片服务是否启用压缩，不把压缩体积当作未验证的网络传输量。相同字符变化序列在 SVG 定义中去重，图片内部只存字形引用和变化时刻。

## 重新生成

使用支持类型擦除的 Node.js 和一个支持 WebGL 的浏览器：

```sh
node --experimental-strip-types scripts/prepare-capture.mts /tmp/langtan-sample-field.js
```

在浏览器执行生成的表达式，并等待返回的 Promise。返回对象包含尺寸、采样参数和两个字符序列。将浏览器执行结果保存为具有 `value` 字段的 JSON 文件后运行：

```sh
node --experimental-strip-types scripts/generate-banners.mts /tmp/langtan-field-capture.json
```

生成结果为 `assets/ascii-header.svg` 和 `assets/ascii-footer.svg`。着色器直接取自原网站，更新时重新提取源文件的 `fragmentShader`，再采样生成，避免另写一套近似动画。

参考：[SVG 图片环境的限制](https://developer.mozilla.org/en-US/docs/Web/SVG/Guides/SVG_as_an_image)、[SVG 属性动画](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/animate)。
