# GitHub 个人主页横幅

顶部和底部均为 854 × 300 的独立 SVG 图片，与原横幅尺寸一致。README 只替换这两张图片，其余内容保留。

- 顶部：`HELLO WORLD`、`I'm Lang Tan`，不含标志。
- 底部：`END`、`Curiosity makes knowledge a game.`，包含个人网站原始标志。

字符集、两层单纯形噪声和流场取样来自个人网站；以 SVG 位移与透明度动画适配图片环境，文字逐字出现并带闪烁光标。它是网页效果的轻量矢量适配，不执行网页实时着色器。

图片不包含脚本、外部字体或逐帧位图。背景动画持续播放，文字出场播放一次。系统启用减少动态效果时显示静态完整文案。GitHub 图片缓存可能延后更新，动画行为取决于客户端图片渲染支持。

## 重新生成

使用支持类型擦除的 Node.js：

```sh
node --experimental-strip-types scripts/generate-banners.mts
```

生成文件为 `assets/ascii-header.svg` 和 `assets/ascii-footer.svg`。原始标志保留在 `assets/logo.svg`。两张生成图片合计约 20 KB。
